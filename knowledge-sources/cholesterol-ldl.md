# LDL Cholesterol Reference Ranges (NIH / NCEP)

LDL ("bad") cholesterol can build up in artery walls over time. Reference categories:

- Optimal: below 100 mg/dL (below 2.6 mmol/L)
- Near/above optimal: 100–129 mg/dL (2.6–3.3 mmol/L)
- Borderline high: 130–159 mg/dL (3.4–4.1 mmol/L)
- High: 160–189 mg/dL (4.1–4.9 mmol/L)
- Very high: 190 mg/dL or above (4.9 mmol/L or above)

Unit conversion: mg/dL = mmol/L × 38.67 (e.g., 3.9 mmol/L ≈ 151 mg/dL = "borderline high").
For mildly elevated LDL, guidelines generally recommend lifestyle changes first.

Source: U.S. NIH (MedlinePlus); National Cholesterol Education Program (NCEP ATP III).
Educational reference only; not a diagnosis.
